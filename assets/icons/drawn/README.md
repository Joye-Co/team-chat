# Icons drawn for the app

Icons of the Windows SVG set that Lucide does not have (`docs/design/WINDOWS.md` §5). Each is a
24-unit SVG at stroke 2 with round caps and joins, like a Lucide icon; a mark cut out of a filled
shape is a mask with its own `stroke-width` (2.5 against the set's 2), which the app scales with
the weight. Licenses: `third_party/lucide/README.md`.
