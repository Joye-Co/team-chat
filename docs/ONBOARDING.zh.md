# 新同学上手指南

欢迎加入！团队的讨论、分工和交付都在 Cahoots 里进行。这份指南带你从下载到发出第一条消息，
再到和机器人成员一起干活。大约需要 10 分钟。

需要：一台 Apple 芯片（M1 或更新）的 Mac，系统 macOS 13 或更新；或者一台 Windows 10（22H2）或 Windows 11 电脑。
下面按 Mac 写，截图说明以 macOS 26 为准；Windows 上的下载、安装和第一次打开见
[INSTALL.zh.md 的 Windows 一节](INSTALL.zh.md#在-windows-上安装)，登录以后的用法一样。

更详细的安装、更新和卸载说明见 [INSTALL.zh.md](INSTALL.zh.md)。

一个人用、还没有服务器的话，先照 [SELF-HOSTING.zh.md](SELF-HOSTING.zh.md) 部署自己的服务器，它最后给你一个登录码，
用它代替下面的邀请码（第 4 步先选 **使用其他服务器…** 填你的服务器地址）。部署好以后直接看第 6、7 节。

## 1. 用邀请链接下载

管理员会私聊发给你两样东西：一个**下载链接**和一个 8 位的**邀请码**（形如 `ABCD-EFGH`）。

1. 在 Mac 上用浏览器打开下载链接。页面会自动开始下载 `Cahoots-<版本号>.dmg`，存到"下载"文件夹。
2. 邀请码先别关掉，第 4 步要用。**邀请码只给你一个人用，只能用一次**，不要转发，也不要发到群里。

链接打不开或提示邀请码无效：找管理员要一个新的。

## 2. 安装

1. 双击下载好的 `Cahoots-<版本号>.dmg`。
2. 在弹出的窗口里，把 **Cahoots** 图标拖到右边的 **Applications（应用程序）** 文件夹上。
3. 在访达侧边栏里点 Cahoots 磁盘旁边的推出按钮。

## 3. 第一次打开（来自身份不明开发者的 App）

Cahoots 是团队内部的 App，没有经过 Apple 公证，所以 macOS 第一次会拦住它。只需要放行一次：

1. 打开"应用程序"文件夹，双击 **Cahoots**。macOS 会提示"未打开 Cahoots"，说 Apple 无法验证它。
   点 **完成**。**不要**点"移到废纸篓"。
2. 打开 **系统设置**（屏幕左上角  菜单 → 系统设置），在左边栏选 **隐私与安全性**。
3. 往下滑到 **安全性** 一节，会看到"已阻止 Cahoots 以保护 Mac"。点它旁边的 **仍要打开**。
4. 再弹出的窗口里点 **仍要打开**，然后用触控 ID 或 Mac 登录密码确认。

之后 Cahoots 会正常打开，以后也不用再放行。

- 找不到"仍要打开"：这个按钮只在你最近一次尝试打开后的大约一小时内出现。先回到第 1 步再打开一次，
  然后马上去设置里找。
- 提示"已损坏，无法打开"：在"终端"里运行
  `xattr -dr com.apple.quarantine /Applications/Cahoots.app`，然后再打开。

## 4. 用邀请码登录

1. 登录界面会显示"欢迎加入团队"。把邀请码输入（或粘贴）到 **邀请码** 的格子里，带不带横线都可以。
2. 点 **加入**。

服务器地址已经填好，不需要改。登录后，App 会把登录凭证存在这台 Mac 的"钥匙串"里，重启后仍然是登录状态。
进去以后，打开菜单 **Cahoots → 设置…**（⌘,），在 **我的资料** 里改成你的名字、岗位和头像。

## 5. 认识界面

Cahoots 只有四个核心概念：**成员**、**群**、**话题**、**产出**。

### 第一次进来

登录后先到 **首页**，这里写着 **从这里开始**，有三个按钮：

- **和 … 聊聊**（按钮上是团队主助手机器人的名字）：打开你和它的私聊（加入时已经建好），不知道从哪下手就先问它。
- **开个话题**：把一件事交给成员。
- **去 … 看看**（按钮上是默认群的名字）：打开你所在的群，看大家在做什么。

你一加入就在默认群里。其他群需要管理员把你加进去。

### 左边栏

从上到下：

- **搜索**（⌘K）：输入名字就能跳到群、私聊、话题或成员，也可以直接交代一件事。
- 搜索框右边是 **筛选** 和 **新建**。新建里有 **新话题**（⌘N）、**新建群…**、**发起私聊…**。
- **首页**、**产出**、**成员** 三个入口一直都在。
- 下面是你所在的每个 **群**，群名下列出话题。默认只列跟你有关的话题（你发起的、交给你的、在等你的、你关注的）；
  别人的话题收在一行「N 个话题，点开看」里，点群名或这一行打开群。想在边栏里看全部，打开 **筛选 → 全部话题**。
- 最下面是 **私聊**：和某个人一对一聊天就是私聊（一个只有两个人的群）。

### 成员

人和机器人（AI 成员）都是成员，地位一样：都可以发消息、接活、交付产出。机器人成员的头像是一个角色形象，
它的岗位标签旁有一个小机器人标记，头像的表情和动效会显示它此刻在做什么（空闲、工作中、等你回复、完成、出错、离线）。
左边栏的 **成员** 列出所有成员，从这里也能发起私聊。

### 群聊和话题

打开一个群，先看到的是它的 **群聊**：大家平常说话的地方，直接写就发在群聊里，不会开话题。在群聊里 @ 一个 AI 成员，
它也在群聊里干活、回结果。

一个 **话题** 就是一件事：讨论、进展、问题和产出都挂在它下面，不会和别的事混在一起。话题只在你想开的时候开：

- 点 **新建 → 新话题**（⌘N）开始一个话题，**第一行就是标题**。写下要做的事；**交给** 一行列出群里的成员，点一下就在第一条消息前写上 `@名字`，就交给了他。
- 群聊里某条消息值得单独跟进：在它的菜单里选 **开个话题**，新话题的第一条会引用它。
- 回复某个话题：点开它，在下面的输入框里写。
- 话题上的标签说明在等谁：比如 **等你回答**、**等你审**、**进行中**、**卡住了**、**完成**。
- 输入框里：回车发送，⇧回车换行；可以引用一条消息、粘贴或拖进图片和文件。

### 首页

开始干活以后，**首页** 汇总在等你的事：**需要你拍板** 的决定，成员 **正在做** 的事，**今天交付** 的结果。
每天打开 App 先看首页，需要你拍板的处理完它就清了。

### 产出

话题做出来的东西叫 **产出**：网页、文件、图片、决定。长内容放进产出，话题里留结论和链接。

- 左边栏的 **产出** 列出所有产出；打开一个话题，右侧也能看到这个话题的产出和版本。
- 网页产出可以切换历史版本；文件用 Mac 上默认的 App 打开。
- 上传文件：点输入框里的 **添加文件**，或直接把文件拖进来，单个文件最大 100 MB。

## 6. @ 机器人干活

在话题里输入 `@`，从列表里选一个机器人成员（比如 `@助手`），写清楚要它做什么，发送。

- 机器人会先在你的消息上点一个 👀 表示收到，然后安静地干活，只在**有结果**、**需要你做决定**或**卡住了**的时候再来找你。做完时它发一张「做完了」卡片，写明结果和证据（PR、测试、产出）。
- 它干活时话题里不会刷屏；它的计划和每一步做了什么，在话题右侧和 **实时查看** 里看。
- 想补充或修改要求，直接在同一个话题里继续写就行，不用再 @。做完以后接着说，它接着上一次的会话和代码做。
- 想让它停下：在 **实时查看** 里点 **停止**。团队没配 AI 服务时，你说一句「停」也能停下你交代的这次；配了 AI 服务时，「停」会被当成补充交给它，不会停下。**暂停** 让它先停一会儿，**继续** 接着做。
- 它要做几类不能撤回或对外的事（比如合并到 main、上生产）时会先停下，发一张卡片问批准人，点 **同意** 或 **拒绝**。
  要批准哪几类，管理员在 **团队管理 → 默认规则** 里勾。
- 它没登录、额度用完、电脑不在线时，会用一句话说清楚原因和该做什么；额度重置、电脑回来以后自动接着做。

### 几个 AI 成员一起做

- 一个话题里可以有几个成员一起或先后在做：@ 谁就是找谁，一条消息 @ 两个就两个都动；不带 @ 的补充交给最近在这个话题开始干活的那个。
  话题右侧 **详情 → 成员** 里能看到谁 **在做**、谁 **参与过**。
- 想让他们一个接一个地做，在话题里第一行写 `@A 先写 → @B 再审`（2 到 6 步），后一步从前一步的结果接着做。话题顶上会显示
  **按顺序做** 和做到第几步，可以 **停止**。
- AI 成员也会自己把事情 **转交** 给更合适的成员，或者把一部分 **分** 给别人做完再交回来；话题里会有一张卡片说明，
  卡片上的 **全部停止** 能把这件事里所有在做的都停下。
- 不确定找谁时，@ 主助手机器人，它会转给合适的成员。

各个机器人负责什么，看它在成员页上的岗位，或者问管理员。

### 让 AI 成员在你的电脑上干活

AI 成员默认在团队的电脑上干活，你什么都不用配。想让它们在你自己的电脑上做你交代的事（一个人用时就是这样），在这台电脑上
装好 Claude Code 或 Codex 并登录，再到 **设置 → 电脑** 点 **用这台电脑**。步骤、三项检查和添加 AI 成员见
[INSTALL.zh.md 的「让 AI 成员在你的电脑上干活」](INSTALL.zh.md#让-ai-成员在你的电脑上干活)。三项检查和 **登录** 按钮在 **团队管理** 里，
只有所有者和管理员能打开；你不是管理员时，在终端里运行 `claude --version`（或 `codex --version`）确认装好，
运行 `claude`（或 `codex login`）登录。

## 7. 通知

通知默认是安静的，只在这几种情况提醒你：

- 有人 @你；
- 某个话题在等你（等你回答、等你审）；
- 你关注的话题有了结果（状态变成完成，或有了新产出）。

你参与过、被 @ 过或被等待过的话题会自动关注。想调整：

- 某个群太吵：打开这个群，在右侧 **群资料 → 通知** 里打开 **静音**，或把 **提醒** 改成 **只有 @我**。左边栏右键这个群也能设置，私聊也一样。
- 某个话题太吵：打开这个话题，在右侧 **通知** 里关掉 **关注** 或打开 **静音**；右键这个话题也行。
- 静音的群、私聊和话题，在左边栏名字后面有一个静音图标。
- **设置… → 通知** 里是对所有群都生效的设置：哪些事提醒你、每日摘要和勿扰时段。
- 第一次收到通知时，macOS 会问是否允许 Cahoots 发通知，请点 **允许**。

## 8. 遇到问题：发送诊断

1. 打开 **设置… → 通用**。
2. 在 **诊断** 里简单写一下发生了什么、大概几点，点 **发送诊断**。
3. 看到"已发送，编号 …"后，在 App 里私聊管理员，告诉他编号。

诊断里有 App 版本、macOS 版本、连接状态和最近的运行记录。发送前会去掉密码和登录凭证，**不包含你的消息内容**。

App 打不开时，在"终端"里把日志打包，用别的方式发给管理员：

```sh
cd ~/Library/Logs && zip -r ~/Desktop/teamchat-logs.zip co.joye.teamchat
```

## 9. 更新

App 会自己检查新版本。有新版本时，窗口里会出现提示，点一下就会下载、安装并自动重新打开，不用再做第 3 步。

如果更新后 macOS 弹窗说 Cahoots 想使用钥匙串里的信息，输入 Mac 登录密码，然后点 **始终允许**。

## 常见问题

- **一直显示"连接中"**：检查网络。网络正常还是这样，就发送诊断（第 8 步）。
- **"邀请码不对"**：检查有没有输错；邀请码只能用一次，已经用过或过期就找管理员要新的。
- **换了一台电脑**：先在旧电脑的 **设置 → 账号** 里加一个登录邮箱，新电脑上就能用邮箱验证码登录；没加的话找管理员要一个新邀请码。
  聊天记录都在服务器上，登录后会同步回来。
- **管理员、所有者是什么**：团队有三种身份。**所有者**（搭服务器的人，可以有几位）和 **管理员** 能打开 **团队管理**，
  管 AI 成员、团队的电脑、AI 服务、模型和审批规则；只有所有者能改别人的身份。新加入的人是 **普通成员**。一个人用时你就是所有者，
  感觉不到这些。
