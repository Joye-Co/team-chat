# 新同学上手指南

欢迎加入！团队的讨论、分工和交付都在 TeamChat 里进行。这份指南带你从下载到发出第一条消息，
再到和机器人成员一起干活。大约需要 10 分钟。

需要：一台 Apple 芯片（M1 或更新）的 Mac，系统 macOS 13 或更新。下面的截图说明以 macOS 26 为准。

更详细的安装、更新和卸载说明见 [INSTALL.zh.md](INSTALL.zh.md)。

## 1. 用邀请链接下载

Joye 会私聊发给你两样东西：一个**下载链接**和一个 8 位的**邀请码**（形如 `ABCD-EFGH`）。

1. 在 Mac 上用浏览器打开下载链接。页面会自动开始下载 `TeamChat-<版本号>.dmg`，存到"下载"文件夹。
2. 邀请码先别关掉，第 4 步要用。**邀请码只给你一个人用，只能用一次**，不要转发，也不要发到群里。

链接打不开或提示邀请码无效：找 Joye 要一个新的。

## 2. 安装

1. 双击下载好的 `TeamChat-<版本号>.dmg`。
2. 在弹出的窗口里，把 **TeamChat** 图标拖到右边的 **Applications（应用程序）** 文件夹上。
3. 在访达侧边栏里点 TeamChat 磁盘旁边的推出按钮。

## 3. 第一次打开（来自身份不明开发者的 App）

TeamChat 是团队内部的 App，没有经过 Apple 公证，所以 macOS 第一次会拦住它。只需要放行一次：

1. 打开"应用程序"文件夹，双击 **TeamChat**。macOS 会提示"未打开 TeamChat"，说 Apple 无法验证它。
   点 **完成**。**不要**点"移到废纸篓"。
2. 打开 **系统设置**（屏幕左上角  菜单 → 系统设置），在左边栏选 **隐私与安全性**。
3. 往下滑到 **安全性** 一节，会看到"已阻止 TeamChat 以保护 Mac"。点它旁边的 **仍要打开**。
4. 再弹出的窗口里点 **仍要打开**，然后用触控 ID 或 Mac 登录密码确认。

之后 TeamChat 会正常打开，以后也不用再放行。

- 找不到"仍要打开"：这个按钮只在你最近一次尝试打开后的大约一小时内出现。先回到第 1 步再打开一次，
  然后马上去设置里找。
- 提示"已损坏，无法打开"：在"终端"里运行
  `xattr -dr com.apple.quarantine /Applications/TeamChat.app`，然后再打开。

## 4. 用邀请码登录

1. 登录界面会显示"欢迎加入团队"。把邀请码输入（或粘贴）到 **邀请码** 的格子里，带不带横线都可以。
2. 点 **加入**。

服务器地址已经填好，不需要改。登录后，App 会把登录凭证存在这台 Mac 的"钥匙串"里，重启后仍然是登录状态。
进去以后，打开菜单 **TeamChat → 设置…**（⌘,），在 **我的资料** 里改成你的名字、岗位和头像。

## 5. 认识界面

TeamChat 只有四个核心概念：**成员**、**群**、**话题**、**产出**。

### 成员

人和机器人都是成员，地位一样：都可以发消息、负责话题、交付产出。机器人成员的头像是一个角色形象，
它的岗位标签旁有一个小机器人标记，头像的表情和动效会显示它此刻在做什么（空闲、工作中、等你回复、完成、出错、离线）。

### 群

左边栏是你所在的 **群**，按最近活动排序，有未读和 @你 的数字提示。和某个人一对一聊天就是 **私聊**（一个只有两个人的群）。
点左边栏的"新建"可以新建群或发起私聊。按 **⌘K** 打开快速切换，输入名字就能跳到群、私聊、话题或成员。

### 话题

每条消息都属于一个 **话题**。一个话题就是一件事：讨论、进展、问题和产出都挂在它下面，不会和别的事混在一起。

- 在群里直接写消息（不选话题）就会开始一个新话题，**第一行就是标题**。也可以点 **新话题**（⌘N）。
- 回复某个话题：点开它，在下面的输入框里写。
- 话题上的标签说明在等谁：比如 **等你回答**、**等你审**、**进行中**、**卡住了**、**完成**。
- 输入框里：回车发送，⇧回车换行；可以引用一条消息、粘贴或拖进图片和文件。
- 话题列表顶上可以筛选 **全部**、**未读**、**等我**。

### 待办

左边栏最上面的 **待办** 汇总所有在等你的事：有人 @你，或者某个话题在等你回答、等你审。
每天打开 App 先看待办，处理完它就空了。

### 产出

话题做出来的东西叫 **产出**：网页、文件、图片、决定。长内容放进产出，话题里留结论和链接。

- 打开话题右上角的 **话题详情**（菜单 显示 → 话题详情），可以看到这个话题的全部产出和版本。
- 网页产出在单独的窗口里打开，可以切换历史版本；文件用 Mac 上默认的 App 打开。
- 上传文件：点输入框里的 **添加文件**，或直接把文件拖进来，单个文件最大 100 MB。

## 6. @ 机器人干活

在话题里输入 `@`，从列表里选一个机器人成员（比如 `@Jojo`），写清楚要它做什么，发送。

- 机器人会先回一句表示收到，然后安静地干活，只在**有结果**、**需要你做决定**或**卡住了**的时候再来找你。
- 它干活时，话题里会实时显示它的回复；在 **话题详情 → 工作过程** 里能看到它每一步做了什么。
- 想补充或修改要求，直接在同一个话题里继续写就行。
- 一个话题只有一个负责人。不确定找谁时，@Jojo，它会转给合适的成员。

各个机器人负责什么，见 [ROSTER.md](ROSTER.md)。

## 7. 通知

通知默认是安静的，只在这几种情况提醒你：

- 有人 @你；
- 某个话题在等你（等你回答、等你审）；
- 你关注的话题有了结果（状态变成完成，或有了新产出）。

你参与过、被 @ 过或被等待过的话题会自动关注。想调整：

- 某个群太吵：在左边栏右键这个群，选 **静音**。
- 在 **设置… → 通知** 里，可以为每个群和私聊选 **所有消息**、**仅 @我** 或 **不提醒**，也可以取消关注话题。
- 第一次收到通知时，macOS 会问是否允许 TeamChat 发通知，请点 **允许**。

## 8. 遇到问题：发送诊断

1. 打开 **设置… → 通用**。
2. 在 **诊断** 里简单写一下发生了什么、大概几点，点 **发送诊断**。
3. 看到"已发送，编号 …"后，在 App 里私聊 Joye，告诉他编号。

诊断里有 App 版本、macOS 版本、连接状态和最近的运行记录。发送前会去掉密码和登录凭证，**不包含你的消息内容**。

App 打不开时，在"终端"里把日志打包，用别的方式发给 Joye：

```sh
cd ~/Library/Logs && zip -r ~/Desktop/teamchat-logs.zip co.joye.teamchat
```

## 9. 更新

App 会自己检查新版本。有新版本时，窗口里会出现提示，点一下就会下载、安装并自动重新打开，不用再做第 3 步。

如果更新后 macOS 弹窗说 TeamChat 想使用钥匙串里的信息，输入 Mac 登录密码，然后点 **始终允许**。

## 常见问题

- **一直显示"连接中"**：检查网络。网络正常还是这样，就发送诊断（第 8 步）。
- **"邀请码不对"**：检查有没有输错；邀请码只能用一次，已经用过或过期就找 Joye 要新的。
- **换了一台 Mac**：找 Joye 要一个新邀请码，在新 Mac 上登录。聊天记录都在服务器上，登录后会同步回来。
