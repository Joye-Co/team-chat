# Windows 对齐清单：界面，逐场景对比

这个文件由 `scripts/windows-scene-table.ts` 生成，不要手改；每个场景看到的差别写在
`interface-scenes.notes.json` 里。主清单是 [interface.zh.md](interface.zh.md)。

- Windows：CI 的 `desktop-windows` 任务，`windows_scenes=all`，**run 43020519758**，产物 `windows-screenshots`（`<场景>-<light|dark>.png`，内嵌页面另见 `screen/`）。
- Mac：一台 Mac 上 `desktop --screenshot` 的结果（2 倍，缩到 1 倍再比）。
- 场景 274 个；Windows 上通过 272 个，失败 2 个（`artifact_ask_pending`、`state-hover-settings-row`）。
- 不算差别、所以不在表里的：标题条和窗口按钮、内容整体下移 32、字体和图标集本身、表情的画法、AI 成员头像（开源构建没有图包）。

所有主窗口场景共有的差别（表里不逐行重复）：

- 字重不同：500 字重画成粗体已修（#156）；半粗中文是雅黑 Bold、中等是 Regular，属字体（没有对应）
- 文字边缘是 ClearType：Windows 自己的文字渲染
- 自测专用窗口没有标题条，或非活动窗口的标题条没变淡：非活动标题条已修（#162）；自测专用窗口不是应用里的窗口
- 等宽字的字体或字重不同：页面里的已修（#162，字体别名）；应用里是 Consolas 加 ClearType，属字体
- 对话框、查看器、面板盖住工具栏行：已修（#156）：从标题条下面算
- 头像字母：字重同上；AI 成员头像是开源构建没有图包
