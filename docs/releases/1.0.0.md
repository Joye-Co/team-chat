TeamChat 1.0.0：团队每天使用的第一个正式版本。人和机器人都是平等的成员，讨论、分工和交付都在这里完成。

## 能做什么

- **群和私聊**：按最近活动排序，未读和 @你 实时同步；⌘K 快速切换；群可以重命名、静音。
- **话题**：每条消息都属于一个话题。直接写消息就开始新话题，第一行是标题。话题状态说明在等谁（等你回答、等你审、进行中、卡住了、完成）。支持 @提及、引用、编辑和删除；每个话题单独记录已读位置。
- **待办**：所有 @你、等你回答、等你审的事集中在左边栏最上面。
- **产出**：网页、文件、图片和决定挂在话题下。单个文件最大 100 MB，图片直接预览，网页在隔离的窗口里打开并保留历史版本。
- **机器人成员**：@ 一个机器人就是请它接手。它先回一句收到，安静干活，只在有结果、需要决定或卡住时回来；回复实时显示，工作过程可以随时查看。
- **卡片**：机器人和集成（GitHub 的 PR、评审和 CI）发的卡片原生显示，按钮直接回传给作者。
- **搜索**：中文两个字的词也能搜到，可以搜当前群或所有群。
- **通知**：默认安静，只在 @你、话题等你、关注的话题有结果时提醒。
- **断线不丢消息**：断网、睡眠、换网络后自动补齐，不丢不重。
- **自动更新**：有新版本时 App 内提示，一键安装并重新打开。
- 浅色和深色模式，界面全中文。

## 安装

1. 打开管理员私聊发给你的邀请链接，下载 `TeamChat-1.0.0.dmg`（有仓库权限的同学也可以在本页的 Assets 里下载，并用 `.sha256` 文件校验）。
2. 双击 DMG，把 TeamChat 拖到"应用程序"文件夹。
3. 打开 TeamChat，输入邀请码，点"加入"。

## 第一次打开：来自身份不明开发者的 App

TeamChat 没有经过 Apple 公证，第一次打开时 macOS 会拦住它，放行一次即可：

1. 双击 TeamChat，看到"未打开 TeamChat"的提示后点"完成"（不要点"移到废纸篓"）。
2. 打开"系统设置 → 隐私与安全性"，滑到"安全性"，在"已阻止 TeamChat"旁点"仍要打开"。
3. 再点一次"仍要打开"，用触控 ID 或登录密码确认。

App 内的自动更新不需要再做这一步。从 1.0.0 起，每个版本都用同一个证书签名，更新后钥匙串会继续信任 App；从旧版本更新到 1.0.0 时，macOS 可能会再问一次钥匙串密码，输入后点"始终允许"。
