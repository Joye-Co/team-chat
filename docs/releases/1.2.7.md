TeamChat 1.2.7：团队管理有了自己的窗口，总览、成员、用量、活动记录和机器都在里面；能看到 AI 成员花了多少钱，到了每周预算会先停下来问；跑成员的电脑可以直接在 App 里登录和配置密钥。

## 怎么更新

- 已经装了 1.2.6：App 里会提示有新版本，点「更新」后自动安装并重新打开。
- 跑成员的电脑也要更新到 1.2.7，才能在团队管理里看到机器概览、登录订阅账号、添加 API 密钥，用量也才能按模型算钱。没更新的电脑照常工作。

## 新功能

- **团队管理**：负责人可以从账号菜单打开「团队管理…」（⌥⌘,）。原来在设置里的团队相关页面都搬到了这里，打开先看到「总览」：成员、话题、花费、产出，谁找 AI 成员最多，以及整个团队「要注意」的事。
- **成员**：一张表列出所有人和 AI 成员，可以按类型切换，点一行在旁边看详情，包括常找的 AI 成员、最常找它的人。
- **用量**：按本周、本月、上个月看 AI 成员花了多少钱，和预算比是多少，有多少已经包含在订阅里。可以按 AI 成员、按发起的人、按机器看。按每次实际用的模型算钱，Codex 的费用按公开价格估算，前面标「≈」。
- **到了预算先停下来问**：给 AI 成员设了每周预算后，花到预算就先停下来，发卡片问负责人：这周再加一点、改预算，或者先停下。加了预算，停着的活会接着做。
- **活动记录**：谁改了成员、级别、邀请、密钥、预算，机器什么时候掉线又回来，哪次干活失败了，都记下来，保留 90 天，可以按人、类型和机器筛选。
- **机器**：每台跑成员的电脑都有「概览」，看 CPU、内存、正在跑的活和要注意的事。可以直接在这里登录 Claude Code 和 Codex 的订阅账号，或者给机器添加 API 密钥并指定给哪个成员用，不用再登到那台电脑上操作。

## 改进

- **邀请可以更早过期**：邀请码可以设成几小时后就失效，默认还是一周。
- **右侧栏宽度统一**：右边的面板可以拖宽拖窄，所有页面共用一个宽度；命令框太长时可以滚动。
- **点头像 @ 一次**：点头像只 @ 这个人一次，不再顺带引用消息。
- **改预算**：打开「改预算」时会选中当前的预算。
