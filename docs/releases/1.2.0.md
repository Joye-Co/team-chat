TeamChat 1.2.0：可以用邮箱登录，群里能直接聊天，话题标题由 AI 来起，新成员第一次打开也知道从哪里开始。

## 怎么更新

- 已经装了 1.1.0：App 里会提示有新版本，点「更新」后自动安装并重新打开。
- 第一次安装：从 GitHub 的发布页下载 `TeamChat-1.2.0.dmg`，拖到「应用程序」文件夹；第一次打开时到「系统设置 → 隐私与安全性」里点「仍要打开」。第一次登录用管理员发给你的 8 位邀请码。
- 服务器先更新。1.1.0 的 App 照常能用，只是看不到这一版新加的东西。

## 新功能

- **用邮箱登录**：在「设置 → 账号 → 登录邮箱」里加一个邮箱（会发验证码确认）。以后换了电脑或退出了登录，在登录页点「用邮箱登录」，收一个 6 位验证码就能登录，不用再找管理员要邀请码。验证码 10 分钟内有效，只能用一次。
- **群聊**：每个群和私聊都有自己的群聊，平时说话就在这里说。要做一件事时，在一条消息上点「开个话题」，新话题会引用这条消息。
- **AI 起标题**：开话题时不用再写标题，什么都不填也可以开，标题由 AI 来起；你自己改过的标题不会被覆盖。管理员在「设置 → 通用 → AI 服务」里选服务商（DeepSeek、Anthropic 或 OpenAI 兼容的接口）、模型并填 API Key，可以先「测试连接」再保存。没有设置时，用第一条消息的第一行当标题。
- **多个账号**：点侧栏底部的头像打开账号菜单，可以「添加账号…」、在几个账号之间切换，或者只退出其中一个账号。App 菜单里的「服务器」可以在正式服务器和测试服务器之间切换，切换时不会退出登录。
- **静音**：在群页面右侧的「群资料」和话题右侧的信息栏里都有「通知」：可以静音，也可以选只有 @我 时才提醒。话题也可以静音了，右键菜单里有「静音话题」。静音的群和话题在侧栏里名字后面有一个静音图标。「设置 → 通知」现在只放全局的提醒和勿扰。
- **撤回和重新编辑**：发出 24 小时内可以撤回自己的消息，撤回后会显示「此消息已撤回」；撤回后可以点「重新编辑」，把原来的文字放回输入框。
- **回复更顺手**：点一位成员的头像，会引用这条消息并 @ 这位成员；双击一条消息，或选中后按 R，也是回复。鼠标停在消息上时，最常用的 3 个表情排在最前面。
- **编辑 AI 成员**：在「设置 → 成员」里，AI 成员的 ⋯ 菜单里有「编辑…」，可以改名字、岗位、工作方式和运行设置。

## 新成员第一次打开

- 侧栏会列出你所在的每个群，群里还没有跟你有关的话题时也会显示。
- 首页显示「从这里开始」：和 Jojo 聊聊、开个话题，或者去全员群看看；其他群要请管理员把你加进去。
- 第一次登录时会自动建好和 Jojo 的私聊。
- 侧栏上方的「新建」菜单可以开新话题、新建群或发起私聊；开新话题时可以直接选交给哪位成员。

## 改进

- 侧栏可以隐藏、拖动改变宽度（双击边缘恢复默认宽度），展开和收起都有动画；侧栏底部的齿轮按钮打开设置。
- 页面顶部的标题栏留出了更多空间，边框也少了，界面更干净。
- 话题的状态、在等谁和负责人都由 App 自动算出来，不用再手动设置；成员页面去掉了「暂停」。
- 资料页上传的头像现在能正常显示了。
- 成员做完一件事后发的结果里，不再重复贴出一段原始数据。
- AI 成员在电脑上干活时，不会再因为没有人批准而在 `git`、`gh` 这些命令上卡住。

## 管理员要做的事

- 把运行机器人的那台电脑上的 daemon 更新到 1.2.0，AI 成员才会用上新的权限设置。
- 在「设置 → 通用 → AI 服务」里填好 AI 服务，话题才会由 AI 起标题。
