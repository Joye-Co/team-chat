1.3.1：话题右栏的「改动」能关上了，也能看到 PR 改了哪些文件；结果卡上的 PR 状态是真的；群、私聊、话题和 AI 成员能隐藏和删除。

## 怎么更新

- 已经装了 1.3.0：App 里会提示有新版本，点「更新」后自动安装并重新打开。
- 跑成员的 Mac 和 Windows 电脑跟着 App 一起更新，Linux 主机的 daemon 会自己更新。电脑更新到 1.3.1 后，结果里的 PR 才会带上状态和改动，也才能在 App 里设它同时做几件事。

## 修好的

- **「改动」关不上**：窗口窄时右栏浮在页面上，右上角的 × 点不动，整个话题就被挡住了。现在能关上。
- 结果卡上的 PR 不再一直显示「未合并」。
- AI 成员的头像又有浅色底了。
- 在输入框里贴一张很长的截图，缩略图不会再伸出来盖住输入框。

## 话题

- **改动**：右栏的「改动」显示 PR 的标题、增删行数、状态和检查，下面是改了的文件，点开看每处改动；能在浏览器里打开。改动由跑成员的电脑用自己的 `gh` 读出来传上来，还没传上来或读不到时会写清楚原因。
- **PR 状态**：成员做完时，电脑用自己的 `gh` 查结果里提到的 PR 是开着、草稿、已合并还是已关闭。PR 合并或关闭后，话题里之前发出的卡片也跟着变。查不到时不写状态，不再猜「未合并」。
- **工作记录**：重新排了版。顶上一张摘要卡写正在做什么或做成了什么；一个话题跑过好几次时，记录列表默认折起，只留最新三条；每一步排成一条时间线，命令和输出放在同一个框里。框里的代码能横着滚时，上下滚动不会再被它吃掉。

## 隐藏和删除

- **群和私聊**：可以隐藏，只对自己生效；别人发来新消息或你再打开私聊时，它会回来。管理员可以删除群，群和里面的消息对所有人都删掉（默认的群不能删）。
- **话题**：可以隐藏，有人 @ 你时它会回来。话题的发起人和管理员可以删除话题，里面的消息、文件、产出和搜索记录都删掉，正在跑的任务也会停。
- **AI 成员**：停用以后，管理员可以删除它。以前的消息还留着它的名字。

## 电脑和上手

- 设置 › 电脑 › ⋯ › 同时做几件事：设一台电脑最多同时做几件事（1 到 100）。能改电脑名字的人就能改这个。电脑还没更新时，最多只能设到它自己配置的数，界面上会写明。
- 首页的「从这里开始」变成一张上手清单：填资料、准备一台干活的电脑、添加 AI 成员、交代第一件事，做完的自己打勾。用邀请码进团队的人，电脑和 AI 成员两步已经勾好。第一次打开 App 会先到首页。

## 给自己部署的人

- 先部署服务器再发版。新的 D1 迁移：`0020_hide_delete`、`0021_machine_limits`，都只加列。
- 协议只加不改，1.3.0 的 App 和 daemon 照常能用。
