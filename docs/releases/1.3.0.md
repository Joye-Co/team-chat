1.3.0：交给 AI 成员的事能做完了。前台接活也盯活，长任务不怕断，几个成员能在一个话题里接力，结果和失败都如实说；电脑分个人的和团队的，Linux 主机的 daemon 能自己更新；Windows 和 Mac 功能一致。应用也换了新名字和图标。

## 怎么更新

- 已经装了 1.2.7：App 里会提示有新版本，点「更新」后自动安装并重新打开。Windows 上用旧名字装的应用也能直接更新过来。
- 跑成员的 Mac 和 Windows 电脑跟着 App 一起更新。Linux 主机这一版起有自己的 daemon 发布物，装上以后会自己更新（见最后「给自己部署的人」）。
- 跑成员的电脑要更新到 1.3.0，才能用接管、按顺序做、续接会话和电脑上的 GitHub 登录。没更新的电脑照常干活。

## AI 成员

- **前台**：@ 谁就交给谁，一条消息 @ 几个成员，每个都会动。交代时带的截图、文件和引用，成员都看得到；它还能读群里的产出、卡片、决定和成员名单，也能读到交代人所在的其他群。追问会发成卡片，话题显示在等你回答。
- **接着说**：做完后在话题或私聊里接着说，不用再 @，会续上同一个会话、同一个工作目录和分支。私聊不再每句话都从头开始。
- **几个成员一起**：话题顶上能看到谁在做。成员之间可以转交、分出去，话题里看得见，也能一键停下。想让他们按顺序做，用「→」把成员连起来（2 到 6 步），话题里有一条按顺序做的进度条，可以停、可以重试。
- **接管**：任务做到一半，可以「暂停」或「接管」。接管时成员先停下，你在命令框里自己动手，交还后它从这一步接着做。在虚拟机里也一样。
- **长任务**：电脑合上盖子或掉线，任务先等它回来，不再取消重来；指定的电脑不在线就排队，上线后自动开始。单步很久也不会被杀。到时限先存档汇报，再自动续一轮。
- **结果和失败**：成员说做不了，话题不会标完成。结果卡上的测试数来自运行记录。失败用一句中文说清原因和下一步：没登录、额度用完、模型不可用、网络、没装 CLI。没登录的电脑不再派活。
- **出错能恢复**：订阅额度撞线时，任务等到重置时间，话题里写几点恢复，到点在同一个会话里接着做。电脑或 daemon 重启后，带着一段恢复说明接着做，已经对外做过的事不会重做。工作目录清理前会先把没提交的改动提交到它的分支。
- **审批**：Claude Code、Codex、ACP 的成员都由代码拦下要批准的操作，换个写法也绕不过，问不到就拒绝。文字批准只认「同意」「拒绝」。团队的电脑上由管理员批准，个人的电脑上由电脑主人批准。卡片点完原地变。密钥可以设成每次用之前先问。
- **记忆**：成员的记忆只在学到它的那个群里用，不串群。「群里的约定」和「我的偏好」有了自己的页面，能看、能改、能撤回。干活时按这次的请求挑相关的记忆，也能自己查。夜间整理按团队时区的凌晨跑，失败了下个小时再试。Claude Code 和 Codex 自带的记忆在成员干活时关掉，记忆只在产品里。
- **AI 服务**：团队管理 › AI 服务里能看到前台、话题标题和摘要、记忆整理各自开没开；没配或连续失败时会提醒管理员。模型只留一个入口，工作记录里能看到这次实际用的模型。走订阅的任务不计入每周预算。

## 电脑

- **用这台电脑**：点之前先检查 CLI 装没装、登录没登录，缺什么当场说清；还会说明成员在这台电脑上和你权限一样。也可以「不再用这台电脑」。
- **个人的和团队的电脑**：每个人都能加自己的电脑，个人电脑只做主人交代的事；团队的电脑只有管理员能管。设置 › 电脑按系统给安装命令。电脑离线、登录失效、磁盘不够时提醒管理员。
- **身份**：团队里有三种身份：所有者、管理员、成员。所有者可以改身份；管理员可以邀请、停用普通成员和管理电脑。
- **GitHub 按电脑登录**：个人电脑用主人自己在那台电脑上的 gh 登录；团队电脑用管理员在主机上登录一次的机器账号，虚拟机从主机借用，不存在虚拟机里。产品不再保存任何人的 GitHub 凭证，原来「连接 GitHub」的页面去掉了，每台电脑的页面上能看到它登录的是谁。
- **Linux 主机**：话题的代码和会话跟着话题留在主机上，仓库的依赖缓存和工具所有成员共用，不再给每个成员一个 20 GB 的家目录。daemon 有发布物，会自己更新。

## Windows

- Windows 和 Mac 功能一致，包括当电脑跑 AI 成员：用这台电脑、暂停和接管、截图、粘贴和拖出文件、空格预览、产出窗口、任务栏角标、托盘、快捷键。
- 安装、卸载和从上一版更新都在发版时测过。

## 其他改进

- 应用换了新名字，图标换成 Jojo；每个成员都有会随状态变表情的头像，所有者可以给 AI 成员换头像。
- 图片按拼图排开，可以全窗口看；输入框里有缩略图。
- 前进、后退能回到刚才看的地方。
- 界面更省电：忙碌转圈和侧栏不再每一帧都重画。

## 给自己部署的人

- 先部署服务器再发版。新的 D1 迁移：`0013_worker_models`、`0016_account_sign_in`、`0016_push`、`0017_github_accounts`、`0017_github_runs`、`0017_machine_owner`、`0017_memory_audience`、`0017_roles`、`0018_ai_service_health`、`0018_run_limits`、`0019_github_off`。原来的管理员都会成为所有者；`0019_github_off` 删掉已存的个人 GitHub 连接。
- 部署用的 wrangler 配置要有两个定时任务：`0 3 * * *` 和每小时一次的 `0 * * * *`，夜间整理才会按团队时区跑。
- Linux 主机：Release 里有 x86_64 的 daemon，用 systemd 跑的 daemon 每小时检查一次并自己更新。从 1.2.7 升上来，用 root 重新跑一次 `scripts/runner/host-setup.sh` 并重建基础镜像。
- GitHub：个人电脑什么都不用做。团队电脑要建一个 GitHub 机器账号，由管理员在主机上 `gh auth login` 一次；没登录时会提醒管理员。步骤见 SELF-HOSTING。
- 新装的话，`scripts/setup-server.sh` 和 SELF-HOSTING 指南能从零部署一台自己的服务器。
- iPhone 客户端还在仓库里开发，不在这一版里。
