TeamChat 1.1.0：重新做的 Mac 版。打开就能看到哪些事在等你、谁在做什么，成员做完的事带着证据回来。

## 怎么更新

- 已经装了 1.0.x：App 里会提示有新版本，点「更新」后自动安装并重新打开，不用再在「隐私与安全性」里放行。第一次打开 1.1.0 时会重新同步一次群里的消息，稍等几秒。
- 第一次安装：从 GitHub 的发布页下载 `TeamChat-1.1.0.dmg`，拖到「应用程序」文件夹；第一次打开时按「完成」，再到「系统设置 → 隐私与安全性」里点「仍要打开」。登录时把管理员发给你的 8 位邀请码填进 8 个格子，也可以直接粘贴。
- 服务器先更新。更新期间 1.0.x 照常能用；新的卡片在 1.0.x 里显示成简单的卡片，引用显示成一行文字，图显示成原文。

## 新的样子

- **像 Mac 原生的 App**：窗口、工具栏、侧栏、按钮、开关、弹出菜单、确认框和图标（SF Symbols）都按 macOS 的样子重新做了。
- **黑白配色**：整个界面只用黑、白、灰；颜色只用来表示状态（等你、出错、做完、进行中），而且旁边总有文字。浅色和深色都重新调过，「增强对比度」和「减弱动态效果」都跟随系统。
- **每个页面都有完整的状态**：加载时有占位，加载失败时写明原因并可以「重试」，没有内容时有提示。名字很长、数字很大、列表很长时也不会挤乱。
- **键盘**：可以用 Tab 键在按钮和输入框之间移动，焦点有清楚的外框；常用操作的快捷键写在菜单栏里，也列在「设置 → 快捷键」。
- **同一件事在各处说法一样**：一个话题的状态和计数，在侧栏、话题、首页、群和成员页面里都一致。

## 新功能

- **首页**：分成「需要你拍板」「今天交付」「正在做」和「排队」。需要你的事可以直接在这里批准或选择；排队的事写明从几点开始排队。
- **侧栏**：上面是首页、产出、成员，下面按群列出话题，每行右边写状态：等你、失败、做到第几步或未读数；成员正在做的话题前面是它的头像。侧栏有三种样式：以工作为中心、以「需要我」为中心、以成员为中心，在侧栏列表上方的「侧栏选项」菜单里换。
- **话题右侧**：负责、计划、改动、产出、用到的决定、在哪干活、用时和成本，一眼看到。等你决定的事固定在输入框上方。
- **单独问**（⌘;）：在话题旁边单独问一位成员（默认 Jojo），它读过这个话题，只有你能看到；它建议的下一步，你按下按钮才会发到话题里。
- **实时查看和接管**：成员用电脑做事时，可以在话题旁边看它在做什么、按步骤回放、看验收标准。点「接管」它会先停下，「交还」后它从这一步接着做；「停止」会结束这次工作。
- **⌘K 交代或搜索**：写一句要做的事，选一位成员交给它（开一个新话题），或按 ⌘↵ 交给 Jojo 安排；也可以搜话题、产出、成员和群。
- **群页面**：群里在做的事、群的说明和群里的决定。可以改群说明（「修改群说明…」），也可以「记一条」决定。
- **成员页面**：每位成员现在在做什么、排队的事、这周完成的话题和成本、最近交付、在哪台电脑干活、需要你批准的事和能用的工具。管理员可以设「汇报给」谁和每周限额（美元；目前只提醒，不会拦住）。最近出错的工作可以「重试」。
- **产出页面**：像访达一样按网格或列表看，可以排序和搜索；打开一个产出能看来龙去脉、各个版本和页面里的回应。
- **卡片**：成员发来的选择、批准、草稿、表单、数据和改动，在首页、话题、群和通知里都长得一样。只有被问的人能操作；回答后卡片收成一行记录，写明谁、什么时候答的。卡片可以把数字、图表、表格和问题放在一起，也可以做成问卷；顶上的状态带写着等你、等别人、处理中、完成、失败或已作废。选择题还有排序、打分、量表、确认、图片选择、矩阵、时间段和投票。
- **每次操作都回到成员**：在卡片里点一个选项、图上的一根柱子、表格的一行，或按一个按钮，都会发给做这张卡的成员，成员在原地改这张卡，并写明「按你点的「…」」。成员新加的内容标着「{名字} 刚加的」。成员一直没回应时，可以「重试」或「不等了」。
- **产出页面两边都能说话**：成员做的网页里的按钮和筛选会发给成员；成员可以把新数据推进你正在看的页面，你也可以在页面里直接问成员。页面下方写明「页面里的操作会发给 {名字}」。页面在沙盒里运行，不能联网，也不能替你批准。
- **引用提问**：表格的一格或一行、图上的一个点、一个数字、计划的一步、改动的一行、截图、图里的节点、网页里的元素，移上去点「问这里」或按住 ⌥ 点一下，就放进输入框，一条消息最多 5 处；也可以「单独问这里」。
- **对话里的图**：流程图、时序图、状态图等直接在消息和卡片里画出来，在这台电脑上画，不联网；可以放大、看原文、复制原文。画不出来时显示原文并写明原因；图太大时只显示原文。
- **更多产出格式**：视频有封面、章节和截帧；音频有波形、要点和文字稿；PDF 可以翻页和搜索；代码只显示成员指出的那几行；表格可以排序；网页和 Markdown 在话题里就能直接看。文件最大 2 GB（以前是 100 MB），上传时显示进度。

## 设置窗口（⌘,）

设置是一个单独的窗口，改了马上生效，不用保存。

- **通用**：启动时打开首页还是上次的话题、登录时启动、菜单栏里显示、声音；版本和服务器地址；「发送诊断…」把最近的运行记录发给管理员，不含密码和凭证。
- **账号**：改名字、岗位和头像；「登录的设备」列出你的账号登录着的每台设备，可以让某台设备退出登录；「退出登录…」时可以同时删除本机数据。
- **通知**：选哪些事提醒你：需要我拍板的事、我交代的事做完了、成员卡住或出错、有人 @我；每日摘要（选一个时间，每天一条系统通知，汇总等你拍板、有了结果、卡住和 @你 的话题；那时 App 没开就不发，下一次一起算）；勿扰时段；按群设置提醒（全部、只有 @我、不提醒）。
- **成员**（管理员）：邀请成员、添加 AI 成员、改级别；「默认规则」：合并到 main 前、发布到生产前、单次花费超过多少之前，AI 成员要先停下来问，以及由谁批准。规则写进 AI 成员收到的任务说明里。
- **机器**：团队的电脑，在线状态、谁在用、版本。云端还没有开放。
- **外观**：浅色、深色或自动；消息文字大小（只改这台 Mac）。
- **快捷键**：所有快捷键的列表，可以搜索。

## 改进

- 成员收到事情时只回一个表情，做的过程不再刷屏，做完了带上证据（PR、测试结果、录屏、产出）。
- 成员在同一个话题里接着做时，会接上上一次的对话。
- 匿名的卡片，回答的人不会被 AI 成员知道。

## 管理员在发布后要做的事

只有 Joye 能做。命令在仓库根目录、在有 `~/.config/team-chat/production/` 的那台 Mac 上运行；不要把令牌或密钥贴进聊天、命令行或日志，只从文件里读。

1. **在 Mac mini 上装 1.1.0 的 daemon**（Jojo 用它在 Mac mini 上干活）。发布时生产环境还没有登记任何电脑，Jojo 的 runner 也还是关着的，所以这一步是第一次安装，按 [USER-ACTIONS.md 第 3 节](https://github.com/Joye-Co/team-chat/blob/main/docs/USER-ACTIONS.md#3-install-the-daemon-on-the-mac-mini) 做，第 2 步不用自己编译，改用发布页里的 daemon：

   ```sh
   gh release download v1.1.0 --repo Joye-Co/team-chat --pattern 'team-chat-daemon-1.1.0-*' --dir dist
   (cd dist && shasum -a 256 -c team-chat-daemon-1.1.0-aarch64-apple-darwin.sha256)
   ```

   在 Mac mini 自己的「终端」里（要能找到 `claude` 或 `codex`，服务会沿用这个终端的 `PATH`）运行 `~/bin/team-chat-daemon doctor`，每行都是 ok 后再运行 `~/bin/team-chat-daemon install-service`。想让「接管」能打开这台电脑的屏幕共享，先在 Mac mini 上打开「屏幕共享」，再在 `~/.config/team-chat/daemon.toml` 里加一行 `takeover_url = "vnc://<Mac mini 的地址>"`（不要写密码）。
2. **打开 Jojo 的 runner**：`bun server/scripts/admin.ts runner --env production --bot 01M6F8JH9Q1QTCHXW3H746P1WE --runtime claude --labels mac-mini`（用 Codex 就写 `--runtime codex`），然后 `bun server/scripts/admin.ts machines --env production`，看到 `mac-mini` 健康、版本 `1.1.0`。在「全员」的一个话题里 @Jojo，它的回复会一段段出来；再在话题里按 ⌘; 单独问 Jojo 一句，确认能答。
3. **以后更新 daemon**：等 `admin.ts machines` 里 `mac-mini` 没有正在跑的工作（daemon 停下时会取消正在跑的工作），把新的 daemon 换到 Mac mini 的 `~/bin/team-chat-daemon`，再在 Mac mini 的「终端」里运行 `doctor` 和 `install-service`（它会重启服务）。1.0.x 的 daemon 也能连 1.1.0 的服务器，但不会收到接管、单独问和接着上次对话这些工作。
