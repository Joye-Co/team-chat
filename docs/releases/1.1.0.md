TeamChat 1.1.0：全新的界面，一眼看到哪些事在等你、谁在做什么。

> 草稿：发布前按最终内容再改一遍。

## 新功能

- **首页**：打开就能看到「需要你拍板」的事，直接在卡片上批准、选择或确认；下面是今天「做完了」的事和证据；右边是成员「正在做」的事和进度。
- **新的侧栏**：话题按群排，每行一个状态：琥珀色的点是在等你，带蓝色圈的头像是成员正在做，打勾是今天做完了。侧栏有三种样式，可以在「设置 → 外观」里换：以工作为中心、以「需要我」为中心、以成员为中心。
- **话题右侧**：谁负责、计划做到第几步、改了什么、产出、用到的决定、用的哪台电脑、用时和成本，都在右侧一眼看到。等你决定的事会固定在输入框上方。
- **单独问**（⌘;）：在话题旁边单独问一位成员（默认 Jojo），它读过这个话题。只有你能看到；它建议的下一步，你按下按钮才会发到话题里。
- **实时查看和接管**：成员用电脑做事时，可以在话题旁边看它在做什么、按步骤回放、看验收标准。点「接管」它会先停下，「交还」后它从这一步接着做；「停止」会结束这次工作。
- **⌘K 交代或搜索**：写一句要做的事，按 ↵ 交给某位成员，按 ⌘↵ 交给 Jojo 安排；也可以搜话题、产出和成员。
- **群、成员、产出**：在主窗口里就能看群里在做的事和群里的决定、每位成员这周做了什么、产出的来龙去脉和各个版本。
- **新的卡片**：成员发来的选择、批准、草稿、表单、数据和改动，在首页、话题、群和通知里都长得一样。只有被问的人能操作；回答后卡片收成一行记录，写明谁、什么时候答的，在成员开始前还能撤回。
- **卡片可以组合**：一张卡里可以把数字、图表、表格和问题放在一起：上下叠、并排、分组、对比、标签页，或者做成一份问卷一起提交。窗口窄了，并排会自动变成上下叠。卡片顶上有一条状态带：等你、等别人、处理中、完成、失败、已作废，不用读内容就知道在等谁。只有两个短选项的问题会并排显示成两个按钮。卡片上的时间是发出的时间，改过也不变；表格里的数字靠右对齐。
- **更多的选择题**：除了单选和多选，还有排序、打分、量表、确认、图片选择、矩阵、时间段和投票。
- **每次操作都回到成员**：在卡片里点一个选项、图上的一根柱子、表格的一行，填一个输入框或按一个按钮，都会发给做这张卡的成员，成员在原地改这张卡。卡片顶上会写：Ledger 更新了这张卡 · 刚刚 · 按你点的「B 站」，别人看到的是「按 Joye 的选择」；成员新加的内容标着「Ledger 刚加的」，淡淡地亮着，直到下一次更新。能点的柱状图一行一根柱子，点中的那根会突出显示，其余的变淡。成员一直没回应时，可以「重试」或「不等了」。
- **产出页面两边都能说话**：成员做的网页里的按钮和筛选会发给成员；成员可以把新数据推进你正在看的页面，你也可以在页面里直接问成员，回答回到页面里。页面下方写明「页面里的操作会发给 Ledger」，后面是页面能发的操作。页面在沙盒里运行，不能联网，也不能替你批准。
- **引用提问**：看到哪里不懂就点哪里问：表格的一格或一行、图上的一个点、一个数字、计划的一步、改动的一行、截图、图里的节点、网页里的元素。移上去点「问这里」或按住 ⌥ 点一下，它就放进输入框，一条消息最多 5 处；成员知道你问的是哪一处和当时的值。也可以「单独问这里」。
- **对话里的图**：成员发来的流程图、时序图、状态图等，直接在消息和卡片里画出来，浅色和深色都对；可以放大、看原文、复制原文。画不出来时显示原文，并写明原因，比如「第 3 行看不懂」；图太大时显示「图太大了，只显示原文」和节点数。
- **更多产出格式**：视频有封面、章节和截帧，可以把一帧发到话题；音频有波形、要点和文字稿；PDF 可以翻页和搜索；代码只显示成员指出的那几行；表格可以排序。网页和 Markdown 文档在话题里就能直接看（网页从顶部开始显示，下面还有内容时底边会渐隐），上传时显示进度和预览的状态。

## 改进

- 成员收到事情时只回一个表情，做的过程不再刷屏，做完了会带上证据（PR、测试结果、录屏、产出）。
- 浅色、深色和「增强对比度」都重新调过；动效会跟随系统的「减弱动态效果」。

## 更新

- 已经装了 1.0.x：App 里会提示有新版本，点「更新」后自动安装并重新打开。第一次打开 1.1.0 时会重新同步一次群里的消息，稍等几秒。
- 第一次安装：按 [1.0.0 的说明](https://github.com/Joye-Co/team-chat/releases/tag/v1.0.0) 下载 `TeamChat-1.1.0.dmg`，拖到「应用程序」文件夹，第一次打开时在「系统设置 → 隐私与安全性」里点「仍要打开」。

服务器会先更新。更新期间，1.0.x 仍能正常使用；新的卡片在 1.0.x 里会显示成简单的卡片，引用会显示成一行文字，图会显示成原文。
