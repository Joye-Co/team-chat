03

扩展方式

组件会继续加。卡片带目录版本；旧版本看不懂的块显示它自带的后备文字；更复杂的界面，嵌入产出。

目录版本目录是 TeamChat 自己的，成员不能加新块

tc.card/2.1目录版本2.0 有 12 种 · 2.1 加 12 种

每张卡写明用到的目录版本。客户端连上时告诉服务器它认得哪几版，服务器按对方认得的版本发卡。成员只能用目录里有的块。

块名字规则回答里带什么
容器 · 都是 2.1 新增
group分组可以收起，收起时一句摘要—
compare对比2–3 个方案并排，带预览选的方案 + 备注
questionnaire问卷最多 5 题，一次提交每题的答案
选择题 · choice 在 2.0 里就有，其余 2.1 新增
choice单选 / 多选加了 min、max 和「其他」选项 id，其他带文字
rank排序拖动或键盘id 的顺序
rating评分1–5数字
scale量表0–10，两端写字数字
confirm是或否两个按钮直接回答true / false
imageChoice图片选择2–4 张，来自群文件选项 id
matrix矩阵最多 8 行 × 5 列每行一个 id
slots时间段最多 12 个，带谁来不了时间段 id
poll投票群里每人一票，结果公开选项 id
出口 · 2.1 新增
embed嵌入产出交互网页，沙盒里运行页面声明的事件
新块先进目录、发新版本，然后才给成员用。成员可以自由组合块，但不能自己定颜色、字号和间距。
